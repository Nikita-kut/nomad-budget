# Импорт истории из Excel

`import_legacy.py` переносит помесячные итоги из старой таблицы: один лист = один зарплатный месяц.
Сам файл таблицы в репозиторий не кладётся.

## Что берётся с листа

- Доходы: столбцы A–C от строки «Категория» до блока расходов. Названия сводятся к текущим
  категориям по ключевым словам; «у себя», «с копилки» и подобные считаются снятием с накоплений.
- Расходы: столбцы B–E под заголовком «Расходы, месяц, факт» до строки «Итог». «Себе» считается
  переводом в накопления.

## Что создаётся в БД

- Архивные псевдосчета «Архив» и «Архив накопления» в базовой валюте.
- Архивные категории для названий, которых нет среди текущих.
- Периоды по циклу 5→5: листы идут подряд, каждому следующему достаётся следующий период.
- `budget_lines` с планом и операции `source = 'legacy'`, датированные началом периода.

## Запуск

```bash
python3 -m pip install --user openpyxl
python3 tools/import/import_legacy.py ~/path/to/workbook.xlsx --dry-run
```

Отчёт покажет таблицу по месяцам и список категорий, которые будут созданы. Когда всё устраивает:

```bash
SUPABASE_URL=https://<ref>.supabase.co \
SUPABASE_SERVICE_KEY=<service_role> \
python3 tools/import/import_legacy.py ~/path/to/workbook.xlsx
```

Повторный запуск удаляет прежние legacy-операции и заливает заново.
