# Приёмка релиза

Перед тегом `vX.Y.Z`, после того как все PR релиза в `main` и CI зелёный.

## Автоматически

- [ ] CI на `main` зелёный: генератор сценариев, регрессии, тесты воркера и вебхука, сборка APK.
- [ ] `python3 tools/quality/reconcile.py` — без нарушений.
- [ ] Миграции релиза применены (`supabase db push --linked`), функция бота выложена, если менялась.

## Глазами, в демо (`?demo`)

- [ ] «Месяц»: «Можно ещё потратить», «Подушка за месяц», «Осталось по кредитам» — без минусов и красного там, где их быть не должно.
- [ ] «План»: «Не распределено» = доход + остаток − кредиты − копилки − конверты − «Себе» (сложить по плиткам).
- [ ] «Кредиты»: «Обязательно в месяц» совпадает с последней точкой графика «Обязательный платёж»; кнопка «Внести платёж» — на сумму, которая ещё не внесена.
- [ ] «Капитал»: прирост = подушка + тело кредитов.
- [ ] Следующий месяц стрелкой в шапке: «Прогноз остатка» — прогноз, а не сегодняшний остаток.
- [ ] Смена базы на USD и обратно — цифры правдоподобны, откат возвращает исходные.

## На своих данных

- [ ] Цифры «Плана» и «Кредитов» совпадают с фактами из `reconcile.py`.
- [ ] Затронутые релизом экраны открыты и просмотрены.

Расхождение в любом пункте — релиз откладывается, расхождение становится тестом в `scenario/RegressionTest.kt`.
